## Architecture decision after GPT-6 Astra review

Use SDK-owned native conversation coordinators and presentation projectors, following the TypeScript coordinator. Reuse existing native conversation snapshots/view models and report/workspace/feed renderers. Construct transports through the existing authenticated AgentlyClient networking stack. Keep old consumers on their existing default; enable AG-UI explicitly in these application checkouts.

Bootstrap canonical transcript, feeds, execution groups and run references together; retain host activities outside chat. Correlate exact client/protocol/native identities and admit only the submitted request. Detach is distinct from cancellation; replay/attach never resubmits effects. Interrupts retain waiting state. Reconciliation after commands must read after older in-flight reads. Account and conversation generations fence all delayed updates. Scoped application notifications trigger reconciliation for background/other-client work.

Implementation ownership: Swift SDK/application and Kotlin SDK/application are separate delegated tasks. SDK/build checks precede actual simulator starter-flow acceptance. Backend-dependent gates remain open until authenticated live data access succeeds.
